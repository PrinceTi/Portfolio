## 🚀 Key Features

* **Interactive Hero Section:** Dynamic title and capability animations powered by `typewriter-effect`.
* **Particle Background:** High-performance particle canvas system powered by `tsparticles`.
* **3D Card Hover Effects:** Interactive perspective tilt on project cards using `react-parallax-tilt`.
* **Real-time Functional Contact Form:** Direct serverless messaging routed directly to inbox using `@emailjs/browser`.
* **Featured Projects Showcase:** Deep dives and live previews for production systems including **Lymphomap**, **LBIL**, **Oddvega**, and **Quizzort**.
* **Embedded Resume Viewer:** Integrated multi-viewport PDF viewer with download and preview actions powered by `react-pdf`.
* **Fully Responsive:** Fluid, mobile-first design system customized with React-Bootstrap and responsive CSS grids.

## 🛠️ Built With

* **Core:** [React.js](https://reactjs.org/)
* **Routing:** [React Router](https://reactrouter.com/) (v6)
* **Styling & UI:** [React-Bootstrap](https://react-bootstrap.github.io/), Bootstrap 5, Custom CSS
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Contact API:** [@emailjs/browser](https://www.emailjs.com/)
* **Visual Effects:** `tsparticles`, `typewriter-effect`, `react-parallax-tilt`
* **PDF Rendering:** `react-pdf`, `pdfjs-dist`
* **Deployment:** [Vercel](https://vercel.com/)
