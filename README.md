## 🚀 Key Features

* **Interactive Hero Section:** Dynamic text animation powered by `typewriter-effect`.
* **Particle Background:** Subtle space/particle network powered by `tsparticles`.
* **3D Tilt Interaction:** Smooth mouse-tracking card tilt effects with `react-parallax-tilt`.
* **Projects Showcase:** Highlighted responsive project cards with live demo and GitHub repository links.
* **Resume Viewer:** Integrated PDF viewer and download action.
* **Fully Responsive:** Fluid layouts designed for mobile, tablet, and widescreen monitors using React-Bootstrap.

## 🛠️ Built With

* **Core:** [React.js](https://reactjs.org/) (v17)
* **Routing:** [React Router Dom](https://reactrouter.com/) (v6)
* **Styling & UI:** [React-Bootstrap](https://react-bootstrap.github.io/) / [Bootstrap 5](https://getbootstrap.com/)
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Effects & Animation:** `tsparticles`, `typewriter-effect`, `react-parallax-tilt`
* **PDF Engine:** `react-pdf`, `@react-pdf/renderer`
